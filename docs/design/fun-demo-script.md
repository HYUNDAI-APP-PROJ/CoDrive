# 엔터 요소 PT 시연 대본 (3분)

흐름: **주행 중 룰렛 잠김 → 신호 대기도 잠김 → 휴게소 도착 후 룰렛으로 톨비 결정 → 도전과제 달성 알림 → 여행 종료 후 여행 카드 완성**

모든 데이터는 시연용 가짜 데이터입니다. 화면 오른쪽 아래의 **시연 조작** 패널(`?dev=1`)로 차량 상태를 바꿉니다. 패널의 시나리오·여행 횟수·여행 종료·초기화 버튼을 누르면 패널이 **저절로 접혀서** 화면을 가리지 않아요. 다시 쓸 때는 **시연 조작**을 눌러 펼칩니다.

---

## 시연 전 준비 (PT 10분 전)

1. 프로젝트 루트에서 로컬 서버를 켭니다.
   ```bash
   python -m http.server 8765 --bind 127.0.0.1 --directory docs/design
   ```
2. Chrome 새 창을 열고, 화면 배율을 100%로 둡니다. 다른 탭은 닫습니다.
3. 아래 주소 3개를 **북마크바**에 등록해 두면 한 번에 이동할 수 있습니다.

   | 이름 | 주소 |
   | --- | --- |
   | ① 룰렛 | `http://127.0.0.1:8765/fun-stop-games.html?dev=1&scenario=driving&trip=3` |
   | ② 도전과제 | `http://127.0.0.1:8765/fun-challenges.html?dev=1&scenario=driving&trip=3` |
   | ③ 여행 카드 | `http://127.0.0.1:8765/trip-card.html?dev=1&scenario=all-arrived&trip=3` |

4. ① 룰렛을 열고 **시연 조작 → 시연 초기화**를 한 번 눌러 이전 기록을 지웁니다. 화면을 다시 불러오면 패널은 접혀 있어요.

> **반드시 같은 탭에서 진행합니다.** 여행 기록(룰렛 결과, 달성한 도전과제)은 탭 안에만 저장되기 때문에, 새 탭에서 열면 카드에 이어지지 않습니다.

---

## 진행 순서

### 1. 주행 중에는 잠겨요 (0:00 – 0:25)
- **주소:** ① 룰렛 (`scenario=driving`)
- **누를 버튼:** 없음
- **보여줄 곳:**
  - 자물쇠 아이콘과 "주행 중에는 사용할 수 없어요. 도착하거나 2분 넘게 정차하면 열려요."
  - 회색으로 잠긴 **룰렛 돌리기** 버튼
  - 왼쪽 현재 경로 패널: 원주 부근 → 횡성휴게소 → 안목해변
- **말할 문장:** "톨비와 주차비를 룰렛이나 사다리로 정하는 기능인데요, 주행 중에는 운전에 방해가 되지 않도록 아예 잠겨 있어요."

### 2. 신호 대기도 잠겨요 (0:25 – 0:50)
- **누를 버튼:** 시연 조작 → **신호 대기 (정차 직후)**
- **보여줄 곳:** "정차한 지 2분이 지나면 사용할 수 있어요. **120초** 남았어요." 숫자가 1초씩 줄어듭니다.
- **말할 문장:** "차가 멈췄다고 바로 열리지 않아요. 신호 대기처럼 잠깐 선 건 안전하다고 보지 않고, 2분 넘게 서 있거나 휴게소·목적지에 도착해야 열려요."

### 3. 휴게소에 도착해서 톨비를 정해요 (0:50 – 1:30)
- **누를 버튼:** 시연 조작 → **휴게소 도착 (일부 차량)** → **톨비**가 선택된 것을 확인 → **룰렛 돌리기**
- **보여줄 곳:**
  - 잠금이 풀리며 "지금 사용할 수 있어요."로 바뀌는 순간
  - 경로 패널의 현재 위치가 횡성휴게소로 바뀜
  - 약 4초 뒤 결과 "톨비는 B 차량이 내요"(차량은 매번 달라요)와 "여행 기록에 남겼어요."
- **말할 문장:** "휴게소에 도착하면 기다릴 필요 없이 바로 열려요. 룰렛으로 톨비 낼 차량을 정하면, 결과가 '함께 내린 결정'으로 여행 기록에 자동으로 남아요."

### 4. 도전과제 알림은 멈췄을 때 보여줘요 (1:30 – 2:15)
- **주소:** ② 도전과제 (`scenario=driving`), 같은 탭에서 북마크로 이동
- **먼저 보여줄 곳 (주행 중):**
  - "부드러운 운전"과 "또 만났네요"가 이미 **달성**(검은 원에 체크)인데 알림은 없음
  - 화면에 누를 버튼이 하나도 없음
- **누를 버튼:** 시연 조작 → **휴게소 전원 합류**
- **보여줄 곳:**
  - 알림 "새로 달성했어요: 쉬어가는 여행 · 부드러운 운전 · 완벽한 합류 · 또 만났네요"
  - 목록에 차량 이름이나 순위가 없고, "함께 4개 달성했어요"처럼 그룹 전체 기준으로만 보임
- **말할 문장:** "도전과제는 모두 공익형이에요. 2시간 전에 15분 쉬기, 공인 연비보다 효율적으로 달리기, 휴게소에서 다 같이 만나기처럼요. 속도나 도착 순서 경쟁은 없고 순위도 매기지 않아요. 주행 중에 달성해도 알림은 미뤘다가, 안전하게 멈췄을 때 보여줘요."
- **마무리:** 알림의 **확인**을 누릅니다.

### 5. 여행을 마치면 카드가 완성돼요 (2:15 – 2:55)
- **주소:** ③ 여행 카드 (`scenario=all-arrived`), 같은 탭에서 북마크로 이동
- **먼저 보여줄 곳:** 제목 아래 "여행이 끝나면 기록이 완성돼요" (진행 중 상태)
- **누를 버튼:** 시연 조작 → **여행 종료 처리**
- **보여줄 곳:**
  - 요약 4칸: 함께한 시간, 방문 장소 2곳, 함께 내린 결정 2건, 달성한 도전과제 4개
  - 함께 내린 결정: "투표 1건 (가결 1 · 부결 0) · 룰렛 1건", 그 아래 **톨비 정하기 · 룰렛 · 결과 B 차량** (3번에서 정한 결과)
  - 달성한 도전과제 4개
  - 맨 아래 **시연용** QR 자리
- **말할 문장:** "여행을 마치면 방문한 곳, 함께한 시간, 같이 내린 결정, 달성한 도전과제가 한 장으로 정리돼요. 방금 룰렛으로 정한 톨비도 여기 들어와 있죠. 이 자리에는 휴대폰에 저장할 QR 코드가 들어갈 예정이에요."

### 마무리 문장 (2:55 – 3:00)
"정리하면, 엔터 기능은 멈춰 있을 때만 쓰고, 경쟁 대신 함께하는 여행을 기록하는 데 집중했어요."

## 실수했을 때 되돌리기

| 상황 | 해결 방법 |
| --- | --- |
| 화면 상태가 꼬였거나 처음부터 다시 하고 싶을 때 | 시연 조작 → **시연 초기화**. 이 탭의 시연 기록을 모두 지우고 지금 주소를 다시 불러와요. ① 룰렛 북마크에서 다시 시작합니다. |
| 4·5번에서 초기화했을 때 | 룰렛 결과가 지워지므로 ① 룰렛으로 돌아가 **휴게소 도착 (일부 차량)** → **룰렛 돌리기**를 다시 합니다(약 15초). |
| 룰렛이 돌다가 "차량이 움직여서 멈췄어요"가 뜰 때 | 돌아가는 중에 주행 상태로 바뀐 거예요. 기록은 남지 않아요. **휴게소 도착 (일부 차량)** → **룰렛 돌리기**를 다시 누릅니다. 오히려 "주행으로 바뀌면 즉시 멈춰요"라고 설명하기 좋은 장면이에요. |
| 시연 조작 패널이 안 보일 때 | 주소에 `dev=1`이 있는지 확인하고, 북마크로 다시 엽니다. |
| 4번에서 알림이 안 뜰 때 | 시나리오가 주행 중인지 확인하고 **휴게소 전원 합류**를 누릅니다. 이미 **확인**을 눌러 알림을 닫았다면 목록의 체크 표시로 설명합니다. |
| 5번 카드가 계속 "여행이 끝나면…"일 때 | **여행 종료 처리**를 다시 누릅니다. "이미 종료한 여행이에요"가 나오면 이미 완성된 상태예요. |
| 카드에 룰렛 결과나 도전과제가 없을 때 | 새 탭에서 연 경우예요. 처음 탭으로 돌아가거나, 초기화 후 1번부터 다시 합니다. |
| 룰렛이 돌지 않고 바로 결과가 나올 때 | 노트북의 "동작 줄이기(애니메이션 줄이기)" 설정이 켜져 있어서 그래요. 정상 동작이에요. 미리 끄려면 Windows 설정 → 접근성 → 시각 효과 → 애니메이션 효과를 켭니다. |
| "또 만났네요"가 달성이 아닐 때 | 주소의 `trip=` 값을 확인합니다. 3이어야 달성이에요. 시연 조작 → **3번째**를 누르면 기록을 다시 시작해요. |

## 시간이 남을 때 보여줄 추가 장면 (선택)
- **사다리타기:** 3번에서 오른쪽 위 **사다리타기**로 바꾸고 **주차비**를 선택한 뒤 **사다리 타기**를 누릅니다. "주차비는 C 차량이 내요"처럼 나옵니다.
- **주행 중 즉시 중단:** 패널을 펼쳐 둔 채 **룰렛 돌리기**를 누르고, 도는 동안 **주행 중**을 누릅니다. 그 자리에서 멈추고 "결과는 정하지 않았어요"가 나옵니다.
- **2시간 휴식 안내:** ② 도전과제에서 **주행 중**을 누르고(패널이 접혀요), 다시 **시연 조작**을 펼쳐 **연속 주행 1시간 59분으로**를 누릅니다. "2시간까지 1분 남았어요"가 나오고, 1분 뒤 "연속 운전이 2시간을 넘었어요. 가까운 곳에서 쉬어가요."로 바뀝니다.
- **또 만났네요 진행 중:** 시연 조작 → **2번째**를 누르면 "이번이 함께하는 두 번째 여행이에요. 다음 여행이면 달성해요."가 나옵니다. 기록을 다시 시작하므로 마지막에만 보여줍니다.
